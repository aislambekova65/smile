# Smile Estetic — Веб-сайт стоматологического центра

Профессиональный сайт для стоматологической клиники на Django.  
Двуязычный (RU/KY), светлая и тёмная тема, панель администратора.

---

## Быстрый старт (Windows)

```
1. Двойной клик на setup.bat
2. Введите данные для admin-панели
3. Сайт откроется на http://127.0.0.1:8000
```

## Ручная установка

```bash
# 1. Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Применить миграции (создаёт db.sqlite3)
python manage.py migrate

# 4. Загрузить тестовые данные
python load_data.py

# 5. Создать администратора
python manage.py createsuperuser

# 6. Запустить сервер
python manage.py runserver
```

## Адреса

| Страница | URL |
|---|---|
| Главная | http://127.0.0.1:8000/ |
| Услуги | http://127.0.0.1:8000/services/ |
| Специалисты | http://127.0.0.1:8000/specialists/ |
| Расписание | http://127.0.0.1:8000/schedule/ |
| Контакты | http://127.0.0.1:8000/contact/ |
| **Админ-панель** | **http://127.0.0.1:8000/admin/** |

## Что можно делать в админ-панели

- **Специалисты** — добавить фото, имя, специальность, биографию (RU/KY)
- **Расписание** — для каждого специалиста задать дни и часы работы
- **Услуги** — добавить название, описание, цену, иконку
- **Записи на приём** — просматривать заявки, менять статус (новая / подтверждена / завершена)
- **Отзывы** — добавлять/скрывать отзывы пациентов
- **Настройки сайта** — адрес, телефон, часы работы, тексты главной страницы

## База данных

Используется **SQLite** (`db.sqlite3`) — файл появляется автоматически после `migrate`.  
Не требует установки сервера БД. Чтобы передать проект другому человеку — достаточно скопировать всю папку.

## Структура проекта

```
smile_dental/
├── clinic/          # Основное приложение (модели, views, admin)
├── templates/       # HTML-шаблоны
├── static/          # CSS, JS, изображения
├── media/           # Загружаемые файлы (фото специалистов)
├── locale/          # Переводы (RU / KY)
├── db.sqlite3       # База данных (создаётся автоматически)
├── requirements.txt
├── load_data.py     # Загрузка примеров данных
└── setup.bat        # Скрипт автоматической установки
```

## Смена языка

Кнопки **RU / KY** в шапке сайта — язык сохраняется в cookie.

## Тёмная тема

Кнопка с иконкой луны/солнца в шапке — тема сохраняется в localStorage.

## Добавление своего логотипа

Замените файл `static/images/logo.svg` на свой файл.

## Деплой на хостинг

1. Установить `DEBUG = False` в `settings.py`
2. Указать `ALLOWED_HOSTS = ['ваш-домен.com']`
3. Запустить `python manage.py collectstatic`
4. Использовать Gunicorn + Nginx
